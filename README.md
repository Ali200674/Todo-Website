# Todo Website (Frontend)

A full-stack Todo website that lets the user create, view, update and delete tasks.
This repository contains the frontend

# Features
 - Create new tasks
 - View tasks
 - Mark tasks as complete
 - Update task information
 - Delete tasks
 - Filter tasks
 - Search up tasks

# Frontend
 - HTML

 - JS
 - React
